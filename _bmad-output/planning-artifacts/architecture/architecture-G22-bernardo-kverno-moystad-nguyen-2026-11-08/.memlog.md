- (direction) Coaching-modus valgt av Heidi. Språk: norsk bokmål.
- (constraint) Faglærer: Vercel er eneste støttede publiseringsløsning (Hobby, gratis, auto-deploy fra main, PR-previews). Støtter Vite/React, Next.js, Node/Express, Python Flask/FastAPI. Repoet må være offentlig; hemmeligheter i Vercel env vars/.env; ingen delte team. Databaser nevnt: Supabase/Neon.
- (constraint) PRD NFR-1: kjørbar lokalt på ren maskin uten betalte tjenester/eksterne kontoer/gruppens nøkler, 'én database kjørt lokalt', 15 min. Spenning mot Vercel (serverless, ingen varig lokal disk): lokal kjøring og Vercel-deploy må begge fungere.
- (constraint) PRD §4.0: statusovergang sjekker gjeldende status i samme operasjon (atomisk, første vinner, andre avvises). NFR-5/10: alle regler og validering på server. NFR-4 passordhash (valg i arkitekturen). NFR-12: CSRF-mekanisme velges i arkitekturen. FR-2: rate limit 5 feil/15 min per e-post, sesjon maks 7 dager. FR-23: 20 KI-forslag/bruker/time. FR-25: 10 s timeout, testdobbel. FR-26 mock-modus uten API-nøkkel.
- (constraint) UX/EXPERIENCE: UI-system ikke valgt; vanlig HTML/CSS holder; native <dialog> showModal; aria-live; vanlige sidelastinger uten skjelett; fokus/kvittering etter sidelasting (tyder på server-rendret). Dato/klokkeslett som tekstfelt. Repo-ryddighet: ingen node_modules/venv i repo. README forutsetter Python 3.11+ og uv.
- (version) Websøk 2026-11-08: Next.js 16.x stabil (kilde nevner 16.4.1 okt 2026; verifiser med npm show next version), Node >=20.9. Vercel Python-runtime: Flask/FastAPI støttet, Python 3.12 default (3.13/3.14 ifølge sekundærkilder), Python-bundle uten tree-shaking. Neon Free via Vercel Marketplace: 0.5 GB, 100 CU-t/mnd; setter DATABASE_URL. Serverless: ingen varig lokal disk, ingen prosess-minne mellom kall -> sesjon, rate limit og KI-kvote må ligge i DB.
- (question) Åpent: framework/språk (Next.js/TS vs Python FastAPI|Flask+Jinja vs Node/Express); DB-strategi (Postgres overalt vs SQLite lokalt+Postgres Vercel); er Vercel-deploy krav eller bonus; gruppens erfaring.
- (decision) Valg 1 (Heidi): Python server-rendret webapp med Jinja-maler (alternativ B). Gruppen er nybegynnere i programmering og lærer underveis. Binder: all UI/server. Hindrer: SPA/React-lag ved siden av.
- (constraint) Vercel-publisering er KRAV (Heidi). Må fungere sammen med lokal kjøring (NFR-1). Vercel Flask: top-level 'app' i app.py/index.py/main.py osv, avhengigheter fra requirements.txt/pyproject.toml, statiske filer i public/, Flask kjører som én Vercel Function.
- (version) SQLAlchemy 2.0.x aktiv (2.0.55 okt 2026), 2.1.x nylig utgitt (2.1.6) -> bruk 2.0-linja til verifisert via pip. Flask 3.1.x (3.1.2 sikkerhetsfiks CVE-2026-27205 -> bruk nyeste 3.1.x, verifiser på PyPI).
- (assumption) Forslag til Heidi, ikke bekreftet: Flask (ikke FastAPI) + SQLAlchemy 2.0 + SQLite lokalt / Postgres (Neon) på Vercel via DATABASE_URL, portabel SQL, statusovergang som betinget UPDATE ... WHERE status=forventet.
